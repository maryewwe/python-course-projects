# Учебные проекты на Python

В этом репозитории собраны лабораторные работы, выполненные в рамках освоения курса "Программирование и обработка данных на Python", первый семестр. Проекты охватывают различные аспекты разработки: реализацию алгоритмов, взаимодействие с API, работу с игровыми механиками.

# Содержание лабораторных

### Лабораторная работа №1 - Криптография

Были реализованы:

- Модуль caesar.py - шифр Цезаря
- Модуль vigenere.py - шифр Виженера
- Модуль rsa.py - ассиметричное шифрование RSA
- Модуль hack.py - криптоанализ

### Лабораторная работа №2 - Сапер

Были реализованы:

- Структура данных и управление состоянием (minesweeper_engine.py)
- Интерфейс командной строки и игровая логика (основной исполняемый файл для взаимодействия с пользователем - play_minesweeper.py)
- Детерминированный решатель (базовый и продвинутый на основе CSP)
- Вероятностный решатель

### Лабораторная работа №3 - PyGit

Было реализовано консольное приложение pygit, которое эмулирует основные команды Git: init, add, commit, log и другие. Работа над этим проектом дала уникальное понимание того, как Git управляет файлами, историей изменений и ветками на самом низком уровне.
